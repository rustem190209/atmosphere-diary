# Дневник атмосферы дня

Прототип для GENESIS Hackathon 2026, кейс ArtTech «Make the Invisible Visible».

Человек пишет, как прошёл день, прикладывает фото и песню. Дневник собирает из этого **воспоминание** — вертикальную анимированную сцену 9:16 под выбранную песню, придумывает дню название и сохраняет всё в **папку дня**. Дни складываются в **архив**.

- Рабочая версия: https://atmosphere-diary-production.up.railway.app
- Техническое задание: [`docs/TZ.md`](docs/TZ.md)

> Это интерпретация настроения, а не диагноз. Приложение не ставит психологических или медицинских оценок.

## Как проверить за 2 минуты

1. Откройте **Архив** — при первом запуске туда загрузятся 3 примера дней.
2. Откройте любой день → нажмите ▶ (звук включается только по кнопке) → вкладка **«Почему так выглядит»**.
3. На странице **«Новый день»** напишите о своём дне, добавьте 1–6 фото и песню (ссылка YouTube/Spotify или аудиофайл) → «Собрать воспоминание».

## Запуск у себя (Windows, PowerShell)

Нужен Node.js 20 или новее.

```powershell
npm install
npm run dev        # http://localhost:3000
npm run check      # автотесты: анализ текста, слияние, правила стиля
npm run build      # сборка для публикации
```

Ключи ИИ не нужны: анализ текста работает по словарю прямо в приложении.

## Как ввод превращается в воспоминание

```
текст + фото + песня (+ чек-ин) → MoodSpec → mapToStyle → параметры сцены + причины → рендер на Canvas
```

| Источник               | Что извлекаем                                                                        | На что влияет                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Текст                  | эмоции (до 3), энергия, напряжение, теплота, время суток, сезон, места, люди, детали | веса техник, название, подпись, голос озвучки, свободное пространство             |
| Фото                   | 5 основных цветов, яркость, контраст, теплота                                        | палитра сцены, теплота дня                                                        |
| Песня                  | темп (BPM), энергия, лад, жанр, год                                                  | ритм смены кадров, движение камеры, приглушённость цветов, зерно для старых песен |
| Чек-ин (необязательно) | насыщенность, эмоции, напряжение, удовлетворённость                                  | уточняет настроение; расхождение с текстом включает двойную экспозицию            |

Все правила детерминированы и записываются в панель «Почему так выглядит». Пример: «Медленная песня (72 BPM) → смена кадра каждые 6 долей ≈ 5 с — медленный ритм даёт кадрам время, больше воздуха».

## Визуальная система

**Постоянные элементы** (одинаковы во всех днях): холст 9:16, рамка фото 4:5 в одном месте, дата вверху слева, «Дневник атмосферы» вверху справа, название под фото, рукописная подпись внизу справа, финальный кадр с названием. Шрифты: Cormorant Garamond (название), Inter (дата), Marck Script (подпись).

**Переменные элементы**: палитра, цветокоррекция, смесь техник, мазки, фигуры, зерно, свечение, виньетка, двойная экспозиция, паспарту вокруг фото, ритм монтажа, движение камеры, толщина шрифта.

Три техники не переключаются, а **смешиваются весами** (например, «живопись 73%, геометрия 14%, плёнка 13%»).

### Художественные приёмы

| Приём                                   | Референс                 | Когда включается                                   | Почему передаёт ощущение                                               |
| --------------------------------------- | ------------------------ | -------------------------------------------------- | ---------------------------------------------------------------------- |

| Плёнка: зерно, засветы, ореол, мерцание | аналоговая фотография    | ностальгия, старая песня, грусть                   | зерно и ореол ассоциируются с памятью и прошлым                        |
| Двойная экспозиция                      | коллаж, мультиэкспозиция | текст и чек-ин расходятся по настроению            | два слоя в кадре — два чувства одновременно                            |
| Пустое пространство (паспарту)          | японский минимализм (ма) | грусть, одиночество, низкая энергия                | воздух вокруг кадра даёт паузу и тишину                                |
| Переход «проявление мазками»            | —                        | ностальгия                                         | воспоминание будто дорисовывается заново                               |

### Названия и голос

Названия — 3–7 слов, именная фраза, без эмодзи и точки: «Осенний день в парке с подругой», «Напряжённая ночь в офисе с командой». Голос озвучки выбирается правилом по настроению: спокойный и тёплый, живой и быстрый, ровный и собранный, тихий и мягкий. Используется только синтезированный голос браузера; музыка под речью тише на 12 дБ.

## Приватность и этика

- Все дни хранятся только в браузере пользователя (IndexedDB). Сервер ничего не сохраняет.
- Без галочки согласия текст не отправляется даже на наш сервер — анализ проходит в браузере.
- Песни по ссылке не скачиваются: они играют во встроенном плеере сервиса. Аудиофайл пользователя остаётся в его браузере.
- Можно удалить любой день или очистить весь дневник.
- Примеры дней — вымышленные тексты; их фото и музыка сгенерированы кодом.

## Известные ограничения

- Темп по аудиофайлу определяет собственный детектор: на 12 синтезированных треках 11 в пределах ±8% (`npm run check:tempo`); на треках с сильным акцентом на 2-ю и 4-ю долю возможна ошибка «вдвое». Поле «характер песни» помогает её исправить. По ссылке темп оценивается по жанру и характеру и помечен «оценочно».
- Лад (мажор/минор) из файла не определяется — без подсказки помечается «неизвестно».
- Архив привязан к браузеру и устройству.
- Озвучка браузерным синтезом не сохраняется в файл — она звучит при просмотре.

## v2: музыка дня, камера, пульс

- **Музыка дня.** Система подбирает саундтрек по профилю дня (текст + опрос + пульс) из 12 пресетов и сочиняет его прямо в браузере (Web Audio, `src/lib/music/`). На экране дня видно, насколько с днём совпала **ваша песня** и что подобрала система, есть переключатель «Звучит: ваша песня | Подобрано системой» и 2 запасных варианта. Ритм монтажа и стиль пересчитываются от того, что реально звучит. Песня пользователя остаётся обязательной — этого требует бриф.
- **Виртуальный оператор** (`src/lib/render/virtualCamera.ts`). Из одного фото получаются разные планы (общий → средний → деталь), смены кадров идут на долях такта, фон и объект двигаются с разной скоростью, на бит и на пики пульса камера делает короткие «удары». Это имитация глубины, а не 3D.
- **Пульс (необязательно).** Демо-кнопки «спокойный / активный / напряжённый» (помечаются «демо-данные») или импорт JSON `{restHr, avgHr, maxHr, series:[{t,hr}]}` («импорт с устройства»). Пульс — контекст, а не подтверждение эмоций: он уточняет только активность дня и даёт моменты пиков.
- **Прямые ссылки на примеры** работают у любого человека: `/day/demo-autumn-park`, `/day/demo-deadline-night`, `/day/demo-exam-day`, `/day/demo-rainy-evening`, `/day/demo-grandma-album`, `/day/demo-lake-weekend`, `/day/demo-festive-dinner`. Если в браузере примеров нет, они загружаются при первом открытии (~15 с).

Тесты v2: `npm run check:v2`.
